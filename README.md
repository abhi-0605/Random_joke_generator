# Random Joke Generator 

A simple web application that displays a random joke whenever the user clicks the **Generate Joke** button.

## Features

* Displays random jokes from a predefined list.
* Clean and responsive user interface.
* Built using HTML, CSS, and JavaScript.
* Beginner-friendly project for practicing DOM manipulation and event handling.

## Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)

## Project Structure

```text
Random-Joke-Generator/
│
├── index.html
├── style.css
├── script.js
└── README.md
```

## How It Works

1. The webpage loads with a default message.
2. When the **Generate Joke** button is clicked:

   * JavaScript selects a random joke from the jokes array.
   * The selected joke is displayed on the screen.

## Installation

1. Clone the repository:

```bash
git clone <repository-url>
```

2. Open the project folder.

3. Open `index.html` in your browser.

## Usage

* Click the **Generate Joke** button.
* A new random joke will appear each time you click.

## Learning Concepts

This project helps you understand:

* DOM Selection (`getElementById`)
* Event Listeners (`addEventListener`)
* Arrays in JavaScript
* Random Number Generation (`Math.random`)
* Updating HTML Content (`textContent`)
